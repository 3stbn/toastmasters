# CLAUDE.md

Guidance for Claude Code when working with this repository.

## What this is

"Habla y verás": an improvisation game (born at a Toastmasters game night,
now audience-neutral). Someone improvises a short talk in Spanish and a screen
reacts in real time, for the whole room including the speaker. Three games, all decided by **TypeSafe
Jev** (a "System One" model that returns structured decisions with
probabilities, never text) called through OpenRouter:

| mode | what Jev answers | what the screen does |
| --- | --- | --- |
| `ilustrador` — Ilustrador automático | `choice` over ~160 doodles (emojis, incl. 25 audience-reaction ones; instruction asks for wit), `score` emphasis (size), `choice` marker colour, every 2nd turn a `choice` over 8 photos | a whiteboard: big emojis that pop in, handwritten labels, arrows between them, polaroids; pages wipe when full |
| `subtitulos` — Subtítulos de la verdad | one `noul` per behaviour in the editable phrase bank (ridiculous/positive tone) | live captions + yellow subtext, history and a live detector meter; fully automatic with a cadence guarantee |
| `banda` — Banda sonora | `choice` over moods | crossfades background music, with hysteresis |

Stack mirrors `../../health-tracker/`: pnpm monorepo, Hono + `@hono/zod-openapi`
on Cloudflare Workers (serving `frontend/dist` as static assets), React 19 +
Vite + Wouter + Tailwind v4 + shadcn-style `ui/` components. No auth: a
session is a 4-letter code backed by one **Durable Object** (`SessionDO`).

## Device roles

Two devices, nothing else (with no projector, two phones work: one creates the
session and is the screen in landscape, the other scans the QR):

- **Screen** (`/s/CODE`, alias `/s/CODE/screen`): the projector laptop. Creating
  a session lands here. Only client that plays audio; starts behind a one-button
  gate ("Empezar") because of autoplay policy, which also goes fullscreen.
  While waiting it shows the code, the QR for the phone, and the three topic
  options. `?mic=1` also runs the mic on this machine; `?nosound=1` skips the gate.
- **Mic** (`/s/CODE/mic`): the phone near the speaker, reached via the QR or
  the code on Home. It is the microphone (browser speech recognition, `es-ES`
  by default, continuous, auto-restart) AND the remote: game, optional topic
  (three drawn from `shared/topics.ts` or typed), Empezar/Parar, next slide,
  another track, throw a subtitle, reset.
- **Ajustes** (`/s/CODE/control`): advanced tuning only, linked from the phone
  footer. Thresholds, phrase bank, full decision log with probabilities.

## Critical: Cloudflare authentication

Same rule as health-tracker: never rely on `wrangler login`. All wrangler
commands go through `backend/scripts/wrangler.sh`, which loads
`CLOUDFLARE_SECRET` / `CLOUDFLARE_ACCOUNT_ID` from the repo-root `.env`:

```bash
cd backend && pnpm cf <wrangler args>
```

Never read or print the values in `.env` or `backend/.dev.vars`.

## Commands

Node 22 (`.nvmrc`), pnpm 10.

```bash
pnpm dev             # backend :8787 (wrangler dev) + frontend :5173 (vite, proxies /api incl. WS)
pnpm run deploy      # build frontend + deploy worker (NOT `pnpm deploy`)
pnpm lint            # tsc both packages — run after changes
pnpm eval            # Jev self-evaluation (needs OPENROUTER_KEY in .env); ~$0.001 per run
pnpm content:slides  # (re)fetch missing slides; `--redo <id>` takes the next Commons result
pnpm content:music   # (re)download + trim missing tracks (needs ffmpeg)
```

Secrets: `OPENROUTER_KEY` is a wrangler secret in prod (`pnpm cf secret put
OPENROUTER_KEY`) and lives in `backend/.dev.vars` locally. `LOCAL_JEV_KEY`
(same handling) authenticates against the local engine below.

## Second engine: SemIf on Esteban's Mac

`../../local-ai/` (personal/local-ai) runs [SemIf](https://github.com/theoleecj/semif)
behind a FastAPI wrapper that speaks the same `/systemone` request shape as
Jev, reachable through a Cloudflare Tunnel at `https://ai.esteban.site/semif/v1`
(`LOCAL_JEV_URL`, `LOCAL_JEV_MODEL` in wrangler vars; locally
`http://localhost:8420/semif/v1` in `.dev.vars`). `settings.engine` (`"jev"` |
`"local"`, default jev, switchable in Ajustes) picks the client per session;
the DO keeps one `JevClient` per engine (local timeout 15 s) and every
decision log carries `engine` + latency. The local service unloads its model
after 15 idle minutes, so the DO calls `JevClient.warm()` (POST `/warm`)
when a session switches to local and on `start`; loading takes ~20 s. When the Worker has no
`LOCAL_JEV_URL` the local engine silently falls back to Jev.
`ENGINE=local pnpm eval` (optionally `LOCAL_JEV_MODEL=Qwen/Qwen3.5-2B`) runs
the same cases against it and prints latency percentiles for comparison.

Deployed at https://topics.esteban.site (custom domain; https://table-topics-ai.stban.workers.dev stays as fallback).

Analytics: Cloudflare Web Analytics beacon in `frontend/index.html` using the
esteban.site zone's site token (the zone's auto-injection does not reach
Worker-served HTML). Dashboard: Cloudflare → Analytics & Logs → Web Analytics
→ esteban.site, filter by host `topics.esteban.site`. Workers observability
(request logs) is enabled in `wrangler.jsonc`.

## Jev notes (from docs.typesafe.ai)

- Request: `{ model, state, questions }`; state can be a string, object or
  array of text; questions evaluate independently and in parallel.
- `noul` → `{ noul: 0..1 }`; `choice` → `{ choice, probabilities, confidence }`;
  `score` → `{ score, legend, probabilities, confidence }` (criteria must be
  an **array** of levels).
- Confidence for an n-way choice is `(n·pmax − 1)/(n − 1)`.
- It is literal, weak at arithmetic/dates, and English is its strongest
  language, so questions/criteria are written in English while the state
  carries the Spanish transcript.
- Model id through OpenRouter: `jev-latest` (bare ids map to the `typesafe/`
  namespace; `typesafe/jev-latest` does NOT resolve).

## Decision logic worth knowing

- All thresholds live in `shared/session.ts` (`DEFAULT_SETTINGS`) and are
  editable per session from the Control page. Behaviours can override the
  subtitle threshold (`threshold` in the bank).
- Evaluation is continuous: the DO calls Jev on interim (still-being-spoken)
  text every ~1.1 s while it changes, not only on final sentences, so reactions
  land ~2 s into a sentence. Engines see recent finals + the interim tail.
- Subtítulos: the screen shows live captions (last finals + interim) in a TV
  caption box; a "truth" replaces the caption in yellow for `subtitleDurationSeconds`.
  Global min gap + per-behaviour cooldown; near-ties are broken at random.
- Banda: EMA over probabilities (alpha 0.55), switch only when the leader
  clears `moodSwitchThreshold` and beats the current mood by `moodSwitchMargin`
  after `moodMinIntervalSeconds`.
- Ilustrador: a doodle is drawn when Jev proposes it twice in a row (or once
  with p ≥ 0.5), at most every `doodleMinSeconds`, never repeating the last 6;
  positions come from a seeded snake path over a 6×4 grid; `doodlesPerPage`
  then a new page.
- The topic is optional: the phone offers three drawn topics plus a free-text
  field; with none, engines get "(tema libre)". The old "turn around" reveal
  cue was removed with the behind-the-speaker premise.
- Subtítulos cadence: if nothing cleared its threshold for
  `subtitleMaxSilenceSeconds`, the most likely behaviour above `subtitleFloor`
  is shown anyway, so the screen never stays quiet.
- Every projector view renders inside `components/screen/Stage.tsx`: a fixed
  1920×1080 stage scaled to fit the real resolution (1024×768, 1280×720…),
  letterboxed on the view's background, so layouts never reflow.
- Music is preloaded by the screen into Web Audio buffers (25 tracks, 90 s,
  64 kbps mono ≈ 18 MB); the screen reports `screenLoaded` and the phone
  disables Empezar until it reaches 1. Downloads retry 3×, `play()` falls back
  to another loaded track of the mood, the AudioContext auto-resumes after an
  interruption, and the phone's «Probar sonido» (`test_sound`) makes the screen
  chime and say «Sonido activado» so the room can verify before a round.
- Sessions are wiped after 12 h idle (DO alarm).
- Abuse caps (the app is shared publicly): a round auto-stops after
  `MAX_ROUND_MINUTES` (10, `shared/session.ts`; `runningSince` + DO alarm, logged
  as a decision), and `QuotaDO` (singleton "daily", `durable/quota.do.ts`) allows
  `DAILY_SESSIONS_TOTAL` (150) sessions per UTC day and `DAILY_SESSIONS_PER_IP`
  (20) per hashed `cf-connecting-ip`; over quota → 429 with a Spanish message
  the Home page toasts. The OpenRouter key should also carry a credit limit.
